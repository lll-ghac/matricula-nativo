## 🔄 **Cómo Restaurar Este Respaldo**

### **Opción 1: Restaurar Base de Datos**
```bash
# 1. Detener el servidor
cd backend
# Ctrl+C para detener

# 2. Respaldar BD actual (por seguridad)
cp ../matricula.db ../matricula.db.backup

# 3. Restaurar desde respaldo
cp backups/matricula_PRE-CONCURRENCY_2025-10-02.db ../matricula.db
cp backups/matricula_PRE-CONCURRENCY_2025-10-02.db-wal ../matricula.db-wal
cp backups/matricula_PRE-CONCURRENCY_2025-10-02.db-shm ../matricula.db-shm

# 4. Reiniciar servidor
npm start
```

### **Opción 2: Restaurar Código desde Git**
```bash
# Ver commits
git log --oneline

# Volver a este punto
git checkout ea290b9

# O crear rama desde este punto
git checkout -b respaldo-v1.1.0 ea290b9
```

### **Opción 3: Restaurar Todo (Código + BD)**
```bash
# 1. Restaurar código
git checkout ea290b9

# 2. Restaurar BD
cp backend/backups/matricula_PRE-CONCURRENCY_2025-10-02.db matricula.db
cp backend/backups/matricula_PRE-CONCURRENCY_2025-10-02.db-wal matricula.db-wal
cp backend/backups/matricula_PRE-CONCURRENCY_2025-10-02.db-shm matricula.db-shm

# 3. Reinstalar dependencias (si es necesario)
cd backend && npm install
cd ../frontend && npm install

# 4. Iniciar sistema
# Terminal 1:
cd backend && npm start

# Terminal 2:
cd frontend && npm run dev
```
